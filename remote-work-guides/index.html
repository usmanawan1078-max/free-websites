The beginner path

  1. Pick one service you can already do or learn fast — see remote jobs for beginners.
  2. Build proof with two or three small sample projects, even unpaid practice ones you label honestly.
  3. Set up a profile that speaks to one kind of client — see how to write an Upwork profile.
  4. Send short, specific proposals — see the proposal guide and finding your first client.
  5. Price fairly and protect yourself — see setting your first rate and scam red flags.
