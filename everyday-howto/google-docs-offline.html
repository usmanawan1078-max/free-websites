How to Use Google Docs Offline

Google Docs normally needs the internet — but with a one-time setup, you can open recent documents and keep editing on a plane, on a train, or anywhere the Wi-Fi drops. Your changes sync automatically when you reconnect.

Before you start

  • Offline Docs works in the Google Chrome browser on a computer. It does not work the same way in every browser, so use Chrome for this setup.
  • You must be signed in to your Google account, and you need internet once to complete the setup and download your recent documents.
  • Offline access works best for documents you have opened recently. Very old files you haven't touched in months may not be available offline until you open them once while online.

Step 1: Turn on offline access in Google Drive

  1. On your computer, open Chrome and go to drive.google.com.
  2. Click the gear icon (Settings) in the top right, then Settings.
  3. Scroll to the Offline section and tick the box for "Create, open, and edit your recent Google Docs, Sheets, and Slides files on this device while offline."
  4. Click Done.

Step 2: Install the Google Docs Offline extension

  1. Chrome usually prompts you to install the Google Docs Offline extension when you turn the setting on. If it doesn't, open the Chrome Web Store, search for "Google Docs Offline", and add the official extension published by Google.
  2. Once installed, the extension runs quietly in the background — there is nothing else to configure.

Step 3: Make specific documents available offline

  1. In Google Drive, find a document you want guaranteed offline access to.
  2. Right-click it (or click the three-dot menu) and turn on "Available offline".
  3. Open the document once while you still have internet, so Chrome downloads the latest version.

Documents marked this way show a small offline indicator. Recent documents are usually available automatically, but marking the important ones removes all doubt.

Working offline: what to expect

  • Editing works normally — typing, formatting, and comments all function offline.
  • Changes sync automatically when you reconnect. You don't need to press anything; just get back online and give it a moment.
  • Collaboration pauses. You won't see other people's live edits while offline, and they won't see yours until you sync. If two people edit the same paragraph offline, Google merges the changes when both reconnect — check the document afterwards if it matters.
  • Some features need internet: adding images from the web, using certain add-ons, and sharing settings. Core writing and editing all work offline.

On a phone or tablet

The Google Docs app on Android and iPhone has its own offline option: open the app, find the document, tap the three-dot menu, and turn on "Available offline". The document downloads to the device and syncs the same way when you reconnect. This is separate from the Chrome setup above — set it per device you use.

If offline mode isn't working

  1. Confirm you're using Chrome (on computer) and signed in to the right Google account.
  2. Revisit Drive settings and check the Offline box is still ticked — signing out or clearing all browser data can turn it off.
  3. Check the extension is installed and enabled in Chrome's Extensions page.
  4. Open the document once while online, then test by turning off Wi-Fi briefly.

If you share a computer with others, remember that offline documents are stored on that device — sign out of Chrome when you finish on a shared machine.
